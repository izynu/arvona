## 🌌 About Arvona

Arvona is a curated directory of legally free resources designed to make the open web easier to explore.

Every resource is opened, reviewed, and dated by a human before being listed.

<div align="center">

| ✅ Human-Verified | 🔓 Open Resources | 🛡️ Privacy-First |
|:---:|:---:|:---:|
| Reviewed before listing | Legally free resources | No ads or trackers |

</div>

**Our principles:** No piracy. No DRM circumvention. No paywall bypass tools. No advertising. No tracking.

## 🖥️ Run locally

### Prerequisites

- [Node.js 20 LTS](https://nodejs.org/) or [Bun 1.1+](https://bun.sh/)
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) (recommended)

### 1. Clone the repository

```bash
git clone https://github.com/izynu/arvona.git
cd arvona
```

### 2. Install dependencies

```bash
bun install
```

Alternatively, use npm:

```bash
npm install
```

### 3. Start the development server

```bash
bun run dev
```

Or:

```bash
npm run dev
```

### 4. Open Arvona

Visit **http://localhost:3000** in your browser.

Press `Ctrl+C` in your terminal to stop the server.

## 🧰 Developer toolkit

| Command | Description |
|---|---|
| `bun run dev` | Start the development server |
| `bun run build` | Export the static site to `out/` |
| `bun run start` | Serve the exported site locally |
| `bun run lint` | Run ESLint |
| `bun run validate` | Validate the resource catalog |
| `bun run catalog` | Regenerate `public/data/catalog.json` |

Both `bun run` and `npm run` work. The repository uses Bun's lockfile.

## 🤝 Contributing

Found something useful? Spotted a broken link? Contributions and corrections are welcome.

1. Fork the repository.
2. Add or fix an entry in `src/data/resources-*.ts`.
3. Follow the field schema and contribution rules.
4. Validate the catalog.
5. Submit a pull request.

```bash
bun run validate
```

The validator checks the catalog schema, duplicate IDs and URLs, missing subcategories, and prohibited copy patterns.

## 🔐 Privacy by design

<div align="center">

<img src="https://img.shields.io/badge/NO_BACKEND-111827?style=for-the-badge&logo=serverfault&logoColor=00C9FF" />
<img src="https://img.shields.io/badge/NO_TRACKERS-111827?style=for-the-badge&logo=proton&logoColor=06D6A0" />
<img src="https://img.shields.io/badge/LOCAL_SAVES-111827?style=for-the-badge&logo=databricks&logoColor=A855F7" />

</div>

Arvona is designed to minimize unnecessary data collection:

- No account is required to browse.
- Search runs client-side.
- Saved items stay in browser `localStorage`.
- The catalog is publicly accessible.
- The project is designed without advertising or tracking scripts.

External websites may follow their own privacy policies and data-collection practices.
